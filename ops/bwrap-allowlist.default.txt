# Default bwrap allowlist — fleet-curated list of cron log-names that
# opt into P1.2 process-level isolation. `script-contract-host.sh`
# reads ~/.clawford/bwrap-allowlist.txt; any LOGNAME matching a line
# here runs under CLAWFORD_ISOLATION_MODE=bwrap.
#
# To flip a cron in or out, edit the installed file on the VPS:
#   ~/.clawford/bwrap-allowlist.txt
# `install-bwrap-allowlist.sh` merges the entries below into it
# idempotently (append-only, dedupe, no destructive rewrite).
#
# Browser-driven crons (Camoufox, Playwright, Firefox) were previously
# excluded because SysV shared memory crashes under the pre-widening
# profile. As of 2026-04-20 the profile adds `--tmpfs /dev/shm`, which
# fixes browser-cron launch under bwrap. They're eligible now; see
# Phase 1d of the brain-improvements plan for staged rollout.
#
# Brain writes: as of 2026-04-20, the profile RW-whitelists
# `brain/{facts,people,commitments,queues}/` (isolation.py). Fact
# miners, daily-refresh, and any other brain-write cron are safe to
# list here. Writes to other brain paths (`brain/memory/`,
# `brain/status/`, etc.) still hit EROFS — by design.
#
# Lines starting with '#' or empty are ignored by the installer.
